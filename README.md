# TaCZ: Zombies
___
A sort of 'sequal' to my Point Blank Zombies' project, this environment runs on 1.21.1 NeoForge - (21.1.235) and uses Kubejs + TaCZ JS for logic.
The modpack, once ready will be exported into these formats by order of priority:
> .zip (Prism) | .mrpack (Modirith) | .zip (Curseforge)

> [!WARNING]
> Any kubejs addons that conflict with 'global.TaCZ_Zombies' will break the scripts
